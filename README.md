 QuantumCalc

QuantumCalc is having standard calculator, scientific-calculator, finance-calculator, unit-converter, 3D and 2D graph depictor and labratories(statistics, ODE, Matrix, Regression)  I made this project keeping  useful calculation tools together in one place.

 Features

- Standard and scientific calculators
- Unit converter
- EMI calculator
- Formula library with 269 formulas
- Date calculator
- Basic graph and experiment tools
- Dark and light themes

 Built With

- Python
- Kivy
